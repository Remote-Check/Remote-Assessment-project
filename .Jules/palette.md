## 2024-05-10 - Explicit label associations missing in clinician forms
**Learning:** Found an accessibility pattern where form labels (`<label>`) were visually present next to inputs and selects, but lacked explicit programmatic linkage (`htmlFor` attribute pointing to an `id` on the input). This breaks click-to-focus behavior and leaves screen readers unable to announce the label when the field receives focus. This pattern appeared in clinician-facing modules like `PatientForm.tsx` and `OrderAssessmentModal.tsx` which were using nested implicit labels incorrectly or just omitting associations entirely.
**Action:** When creating or modifying forms, always ensure labels use the `htmlFor` attribute explicitly linked to the `id` attribute of the corresponding input/select field. Ensure we search across files to find similar missing attributes on form components.
