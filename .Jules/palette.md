## 2024-06-18 - Form Accessibility: Grouped Inputs and Labels
**Learning:** Screen readers struggle with grouped inputs like Date of Birth (Day, Month, Year) when they aren't explicitly associated. While visual users see them grouped under a common label, screen reader users miss that context unless the inputs are wrapped in a `<fieldset>` with a `<legend>`. Additionally, all `<label>` elements must explicitly use the `htmlFor` attribute matching the input's `id` for proper announcement and to enable click-to-focus behavior.
**Action:** Always wrap grouped, related inputs (like dates, addresses, or specific metric groupings) in a `<fieldset>` with a descriptive `<legend>`, and give each individual input a visually hidden (`sr-only`) label. Ensure every input in the application has an explicit `id` and a corresponding `htmlFor` label.
